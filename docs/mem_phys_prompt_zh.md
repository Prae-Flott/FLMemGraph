# 设计提示词:记忆检索 + 物理验证的无监督流式异常检测

> 用途:可直接交给团队作为实现蓝图,或作为 system/task prompt 给 LLM 生成迭代代码骨架。方案既作为文档接受审计,针对对象为多设备边缘平台(机器人集群 + 云端汇聚自动分集群),核心约束是**无标签、隐私、设备异质、工作持续演移**。
> 配套流程图见 `mem_phys_flow.png`。

---

## 0. 一句话目标

在**不共享原始数据、不依赖人工标签**的前提下,为一个不断增长与工作持续变化的多设备集群,搭建一个**长期不误报**的无监督异常检测系统。设想是这样一个东西:**离散化记忆(工位字典)+ GDN 关系图(结构/物理判断)+ 部署可观测性的长效字典**,并用稀缺标签仅在边缘的疑难处。

---

## 1. 核心设计假设(必须先认同的判断)

1. **单一信号无法区分"新的正常工作"与"真的异常"。** 二者在"离已知模式远(距离/记忆距离大)"这个信号上表现相同。这是所有"在正常数据上学正常、靠偏差判断"方法(GDN、autoencoder、one-class、FEDPM)共有的开集(open-set / OOD)根。
2. **必须引入第二个正交信号来打破这个歧义。** 借用 GDN 的关系图一致性:**新正常工况通常仍遵守传感器/物理规律关系图,真正异常倾向于打破关系图。**
3. **记忆用离散原型,不用模型参数。** 参数是"一个纠缠的平均正常函数",不可寻址、易被污染、会被持续训练覆盖(遗忘);而原型是"一本可查询、可工况分类、可选择性共享的字典"。参考 FEDPM(Deng 等, 2026, arXiv:2604.04475)。
4. **训练时字典开放(吸收新模式),部署时字典有节制的增长(由第二信号 + 持续性 + 标签末端把关)**,而不是训练完就停。

---

## 2. 系统三层结构

| 层 | 内容 | 作用轴 | 是否跨设备共享 |
|---|---|---|---|
| A. 本地时序编码器 | 每设备种类、跨端权重共**享** encoder,产出抽象向量 $z_i$ **同时喂给 B 与 C 两个头**(训练时带 decoder,推理时可裁,见 §2A/2B) | 时间(种类动态) | 否(轻量本地) |
| B. 离散化记忆(工位字典) | 每设备/每子域一本 M 个 D 维原型,VQ-VAE 式量化 | 工位(可寻址检索) | 是(只传原型) |
| C. GDN 关系图 + 物理骨架 | 传感器嵌入学出的关系图(物理耦合/骨架/编码),得注意力**在 A 的潜向量 $z_i$ 上**做潜空间一致性残差 $r_i$(不解码回原始值,见 §2B) | 空间/结构(加权残差) | 视情况可共享(物理约束通用) |

**分工白话:** 本地管时间与种类细节;字典管"当前属于哪种已知工况";关系图管"结构要素是否被破坏"。异常判断 = 记忆距离(工位基线)+ 关系图残差(结构判断)的联动判定,而非任一单一值。

## 2A. encoder 与 GDN 图注意力如何合并(边缘计算量省小)

### 2A.1 现状的冗余(必须消除)

上表把 A(本地时序编码器)与 C(GDN 关系图 + 图注意力)分开,若按字面分开建一套,同一路原始信号会被**编码两次**:一次给记忆路(encoder→z→量化),一次给结构路(GDN 自带的时序卷积端→图注意力)。时序编码端本是整个系统里唯一的灵活(要处理变长窗口),两边差异等于边际重复。**这是当前设计最该改的地方。**

### 2A.2 合并方案:一个共享 encoder,两个轻头共用它的输出

把两条路的时序编码端合并成一个:

```
原始 patch x_i (每通道)
      ↓
      ▼  ← 唯一的灵活:共享的跨通道权共享时序编码器 f_θ(PatchTST 式)
   z_i ∈ R^D      (每个传感器一个 D 维潜向量)
   ─────────────────┴────────────────
   ▼                               ▼
[记忆头]                        [结构头]
最近原型索取 → 距离 d_i          在(物理裁剪过)TopK 图上做
(零额外参数,只算距离)          一层图注意力融合邻居 z_j → 上下文 ẑ_i
                                残差 r_i = ‖z_i − g(ẑ_i ; v_i)‖
```

三条关键改动:
1. **只有一个时序编码器 $f_\theta$**,跨每个通道权共享(通道无关,如 PatchTST 的 patchify)。这是全系统唯一的重计算。
2. **GDN 的图注意力改用 $D$ 维潜向量 $z_i$,不再用原始窗口。** 注意力的输入维度从窗口长 $W$ 降到 $D$($D\ll W$),而 GDN 学到/图注意力本来就在节点嵌入上算,这一步天然兼容。
3. **记忆头几乎零成本**:量化只是查最近原型 + 算距离,不含新网络。

### 2A.3 简单账(每设备每 patch)

| 计算项 | 分离式(现状分离) | 合并式 | 省在哪 |
|---|---|---|---|
| 时序编码端 | 2 份(记忆路 + GDN 端路) | **1 份** | 灵活省半 |
| 图注意力输入维度 | 原始窗口 $W$ | 潜向量 $D$($D\ll W$) | 注意力 FLOPs ↓ |
| 邻边权重 | 学 $N\times N$ 全连接 | 物理骨架裁剪成 $N\times K$ | $O(N^2)\to O(NK)$ |
| 记忆头 | — | 查表 + 距离(≈0) | — |
| 推理需解码器 | 需要(预测原始值) | **可裁**(见 2B) | 省一次解码 |

对边缘设备,合并这一行起来通常能把 patch 的算力量省到分离式的 **1/3 ~ 1/2**,且不牺牲两条正交信号(工位距离 + 结构残差)。

## 2B. 混合结构上,GDN 还要不要给每个 feature 维护 predictor?

**先纠正一个常见误解:GDN 从来不是 N 个独立预测网络。** GDN 用的是**一个权共享的输出 MLP**,配节点嵌入 $v_i$ 和邻域条件,产出 N 个标量预测。所谓 "per-feature predictor" 其实是**隐节点的输出**(N 个数),不是 N 套参数。所以"维护 N 个 predictor"这个担心/参数成本**本来就不存在**——不用为它操心。

真正该问的是:**混合结构上,还需要"预测每个传感器的下一个原始值→算绝对差"这条路吗?** 答案:**不需要,可以换成潜空间的图一致性残差**,整套信息等价。

### 2B.1 把"预测原始值→差值"换成"潜空间图一致性残差"

- **原 GDN**:图注意力融合邻居 → 共享 MLP 预测节点 $i$ 的下一个**原始值** $\hat x_i$ → 差值 $|\hat x_i - x_i|$。这需要一路能表示**解码到信号空间**。
- **混合版**:直接在**潜空间**处理关系是否自洽——
$$r_i=\big\|\,z_i-g(\operatorname{AGG}_{j\in\mathcal N(i)} z_j\,;\,v_i)\,\big\|,\qquad g=\text{一个共享、以 }v_i\text{ 为条件的轻 MLP}.$$
即"用邻居的潜向量去重建节点 $i$ 的潜向量",重建不上就是结构被破坏。这条**复用了前边记忆头的同一个 $z_i$**,推理时**不需要解码器**(解码器只在训练期为预测损失/惩诺损失服务)。

### 2B.2 这样做同时满足三点

1. **保留异常定位**:$r_i$ 仍是**隐节点**的(哪个传感器破坏了图,不彼可见)——per-node 残差 → per-node 网络,定位能力不丢。
2. **参数更小**:一个共享条件 MLP $g$ 取代 GDN 的"输出层 + 解码到原始空间"。
3. **两个头天然对齐**:记忆距离 $d_i$ 和结构残差 $r_i$ 都在同一个 $z_i$ 上算,纲量/尺度一致,联动判定(第 5 节)更稳。

### 2B.3 结构变更小结:留什么、并什么、去什么

| 组件 | 处置 | 理由 |
|---|---|---|
| 时序编码端 | **合并**成唯一共享 encoder $f_\theta$ | 消除份编码,边缘计算量主项 |
| 节点嵌入 $v_i$ | **保留**(每传感器一个 $D$ 维向量) | 学得(TopK)+ 给共享头做条件,都需要 |
| 图注意力 | **保留**,一层,共享;改输 $z_i$ | 结构信号来源,输入低维改便宜 |
| 隐节点原始值 predictor | **换成**潜空间残差头 $g(\cdot;v_i)$ | 一个共享条件 MLP,省解码 |
| N 个独立预测网络 | **本来就不存在**(GDN 是共享+条件) | 澄清误解,无需优化 |
| 原始值解码器 | 训练期用的。**推理期可裁** | 推理只需潜空间的 $d_i,r_i$ |
| 邻边权重 | 用物理骨架**裁剪** $N\times N\to N\times K$ | 省算图注意力,$O(NK)$ |

> 最终结构一句话:**一个共享时序编码器产 $z_i$ → 记忆头(量化 $d_i$)+ 结构头(潜空间图一致性 $r_i$),两头共用 $z_i$ 与节点嵌入 $v_i$,推理不解码。** 这样 GDN 的部件都在,"学得 + 图注意力 + 隐节点残差"都在,只是"预测原始值 + 解码"被更省的潜空间残差替代。

## 3. 工位字典(离散化记忆)如何获得与更新

**本地回路(每训练步,无标签):**
1. 数据窗口切分 → patch → encoder → 潜向量 z。
2. 每个 z 检索最近原型(欧氏距离),被量化替换为 ẑ。
3. 三项损失:预测损失 `L_Pred=SmoothL1`;承诺损失 `L_ME=‖z−sg(ẑ)‖²`(拉 encoder 往回);码本损失 `L_MC=‖sg(z)−ẑ‖²`(拉原型移动到命中的 z 段)。**原型只被 L_MC 更新** → 本质是在线 k-means 质心移动,每个原型最终成为"映射到它的所有工况的段的质心"。
4. `sg`(stop-gradient)截断 encoder 与字典的梯度互干扰 → 原型与数据在优化上解耦。

**跨设备回路(每若干轮,服务器):**
1. 客户端只上传字典 P_n(不上传数据、不上传权重)。
2. **对齐**:原型置换不同,不能直接平均;改用余弦相似度连边(阈值 δ)+ BFS 找连通分量 = 语义对齐的跨设备工位环。
3. **共享原型**:每个环均值池化;共享数量上限为总容量的 γ 比例(取占用最大 top-K)。
4. **个性化原型**:剩余槽位从未聚类原型里按用途性维度打分(Freq 高 + 与其设备不相似),保住本设备独有工况。
5. 拼接 `P_G,n=[P_S; P_p,n]` 回发,作为下一轮本地字典初始化。

## 4. 原型与真实数据的分离(隐私边界)

一切不可逆转换,使"共享记忆 ≠ 共享数据":
1. **编码**:原始波形 → 抽象潜向量(离弃信号空间)。
2. **量化(多对一)**:成百上千 patch 映射到同一个原型,原型是它们的质心,单条数据不可反还。
3. **跨设备融合**:共享原型是"质心的质心"。

**评定的边界:** 原型是隐私良好、非隐私证据、低 Freq 项接近这个例;字典本身仍可泄露分布层面信息。若合规要求高时(GDPR/CCPA),上传原对原型加差分隐私噪声声明走安全边界;并对共享原型限制少 Freq 曝光,禁止用极小频次这个例的原型代表法。

## 5. 运行时决定逻辑(对应流程图)

对每一个进来的段 x:

1. 计算**信号1 = 记忆距离 d**(到最近原型)。**信号2 = 关系图残差 r**(GDN 预测)。
2. **d 小** → 命中已知工况 → 正常(常态记忆存在时不上传反馈)。
3. **d 大 + 关系图被破坏** → 真异常 / 攻击 / 撞击 → 立即报警。
4. **d 大 + 关系图仍成立 + 瞬时孤立小峰** → 软报警 / 观察(不长入字典)。
5. **d 大 + 关系图仍成立 + 持续段落出现** → 疑似新工况 → 进程缺标签队门(低频人工确认队列)。
    - 确认正常 → **字典生长**:新增原型(码本损失在线更新)→ 不再触发反馈。
    - 确认异常 → 报警。

**关键直觉:** 真异常是短暂、孤立、打破关系图的;新正常工况是持续、稳定、不仿它关系图的。用这两点拆开歧义分界。

---

## 6. 与项目主线("无标签解决真实运行数据的标签问题")的对齐

- 原型完全无监督学出(VQ-VAE 惩诺损失,不需标签),每个原型 = 一个自监督工况聚类靶点。
- 标签只用在**边界确认队列**这一小处,极小化,不影响无监督主干。
- 反馈只共享工位字典与关系图残差,原始运行数据永不出设备。

---

## 7. 需要团队定的开放问题

- 原型容量 M、维度 D、patch 长度 S(FEDPM 用 M=256, D=64, S=4 作起点)。
- 对齐阈值 δ、共享比例 γ、字典长度的分裂子门(持续性窗口长度、瞬时最小计数)。
- 关系图残差 r 的"破坏"判定阈值,以及物理骨架图如何编码进 GDN 的初始边权。
- 差分隐私噪声强度 vs 原型可用性的权衡;共享原型最小 Freq 门控。
- 开集/闭集的评测协议(目前此方向缺共享区域)。

### 8.3 评测指标(按数据集对齐论文口径)

- **A/B 异常检测**:Precision / Recall / **F1**(GDN、GDformer、FedKO、FedKAD 主指标),时序用**point-adjusted F1**(注意:近年有工作指出 PA-F1 会高估估,建议同时报 **F1 without PA** 与 **AUC-PR / VUS-PR** 以防误导)。
- **B 图像**:**I-AUROC**(图级)、**P-AUROC** + **PRO**(像素级定位),对齐 FedDyMem。
- **C 动态图**:**AUROC** + **AUPRC**,对齐 DP-DGAD。
- **D 预测**:**MSE** / **MAE**,对齐 FEDPM。
- **反馈额外维度**:通信量(每轮上传字节)、边缘推理延迟、内存占用 —— FedKO/FedKAD/FedDyMem 都强调这一项,是我们"只传原型 + 潜空间残差"的简化主张的验证口径。

### 8.4 我们方案必做的消融(证明每个分点)

1. **去掉图/物理第二信号**(退化成纯记忆距离)→ 测识别"新工况 vs 真异常"分离能力多少 = 证明第二信号价值。
2. **GDN 原版(预测原始值)vs 潜空间残差头** → 测 §2B 改造在什么 F1 差距下的推理算量省多少。
3. **分离 encoder vs 共享 encoder**(§2A)→ 测每 patch FLOPs / 延迟下降。
4. **参数平均(FedAvg on encoder)vs 只传原型** → 在 non-IID 分域(如 SMD 的 28 源、FEDPM 的每域一客户端)上测 F1 差距 = 证明原型的 non-IID 韧性。
5. **字典僵化 vs 在线增长** → 在工况迁移区间上测长期误报率。

### 8.5 落地注意

- 数据集获取:SWaT/WADI 需向 iTrust(新加坡科技大学)申请;SMD/SMAP/MSL/PSM/ETT/MVTec 均可公开下载。
- non-IID 分域协议要统一(建议 Dirichlet(α) 控制 skew,或直接按天然实体分,如 SMD 28 源、FEDPM 7 域)。
- 与最近邻(FedDyMem、DP-DGAD、FedKO)对比时,务必在**同一数据集、同一分域、同一指标口径**下跑,避免引用各自论文数字(评测协议不可比)。
